# ติดตั้งบอทให้ตอบได้ 24 ชม. โดยไม่ต้องเปิดคอม

**ใช้เวลา ~15 นาที · ฟรีถาวร · ไม่ต้องใช้บัตรเครดิต · ไม่ต้องลงโปรแกรมอะไรเลย**

Cloudflare Workers ให้ฟรี 100,000 คำขอ/วัน — คุณพิมพ์วันละ 20 ครั้งก็ยังไม่ถึง 0.02% ของโควตา

---

## เทียบกับทางอื่น

| ทาง | ตอบเร็ว | ต้องเปิดคอม | ค่าใช้จ่าย |
|---|---|---|---|
| `rain_bot_interactive.py` บนคอม | ทันที | **ต้องเปิด** | ฟรี |
| **Cloudflare Worker** ⭐ | ทันที | ไม่ต้อง | ฟรี |
| GitHub Actions | ช้าถึง 1 ชม. | ไม่ต้อง | ฟรี |

> GitHub Actions ทำงานแบบตื่นมาทำแล้วหลับ ใช้ตอบโต้แบบทันทีไม่ได้
> จึงเหมาะกับ**การแจ้งเตือนตามเวลา**เท่านั้น (ที่ตั้งไปแล้ว) ให้ใช้คู่กันไป

---

## ⚠️ อ่านก่อนเริ่ม

Telegram อนุญาตให้ใช้ **getUpdates หรือ webhook อย่างใดอย่างหนึ่ง** ไม่ใช่ทั้งคู่

แปลว่าพอตั้ง Worker เสร็จ **ต้องปิด `rain_bot_interactive.py` บนคอม** (กด Ctrl+C)
ไม่งั้นสองตัวจะแย่งกันอ่านข้อความ แล้วบอทจะตอบบ้างไม่ตอบบ้าง

ส่วน GitHub Actions ไม่ชนกัน เพราะมันแค่ส่งออก ไม่ได้อ่านข้อความเข้า

## ขั้นที่ 1 — สมัคร Cloudflare

1. เข้า https://dash.cloudflare.com/sign-up
2. สมัครด้วยอีเมล (ไม่ต้องใส่บัตรเครดิต ไม่ต้องมีโดเมน)
3. ยืนยันอีเมล

---

## ขั้นที่ 2 — สร้าง Worker

1. ในหน้า Dashboard เมนูซ้าย กด **Compute (Workers)** หรือ **Workers & Pages**
2. กด **Create** → เลือก **Start with Hello World!** → กด **Get started**
3. ตั้งชื่อ เช่น `rain-bot` (ชื่อนี้จะกลายเป็นส่วนหนึ่งของ URL)
4. กด **Deploy**
5. จะได้ URL แบบ `https://rain-bot.ชื่อบัญชีคุณ.workers.dev` — **คัดลอกเก็บไว้**

---

## ขั้นที่ 3 — วางโค้ด

1. กด **Edit code** (หรือ **< > Edit code** มุมขวาบน)
2. **ลบโค้ดตัวอย่างที่มีอยู่ให้หมด** (คลิกในช่องโค้ด กด Ctrl+A แล้ว Delete)
3. เปิดไฟล์ `worker.js` ในโฟลเดอร์นี้ คัดลอก**ทั้งไฟล์**ไปวาง
4. กด **Deploy** มุมขวาบน

---

## ขั้นที่ 4 — ใส่ค่าลับ

1. กลับไปหน้า Worker กด **Settings** → **Variables and Secrets**
2. กด **Add** ทีละตัว รวม 6 ตัว

| Name | Type | Value |
|---|---|---|
| `TELEGRAM_TOKEN` | **Secret** | TOKEN จาก BotFather |
| `TELEGRAM_CHAT_ID` | **Secret** | CHAT_ID ของคุณ |
| `WEBHOOK_SECRET` | **Secret** | ตั้งเองอะไรก็ได้ เช่น `bpk-rain-2569-xyz` |
| `WX_LAT` | Text | `13.53` |
| `WX_LON` | Text | `100.99` |
| `WX_PLACE` | Text | `บางปะกง` |

3. กด **Deploy** อีกครั้งให้ค่าใหม่มีผล

> **`WEBHOOK_SECRET` คืออะไร** — URL ของ Worker เปิดสาธารณะ ใครเดาเจอก็ยิงได้
> รหัสนี้ใช้ยืนยันว่าคำขอมาจาก Telegram จริง ตั้งเป็นอะไรก็ได้ที่เดายาก
> แต่ต้องใช้ค่าเดียวกันในขั้นที่ 5

---

## ขั้นที่ 5 — บอก Telegram ให้ส่งข้อความมาที่ Worker

เปิดเบราว์เซอร์แล้วพิมพ์ URL นี้ (แทน 3 ส่วนด้วยของจริง):

```
https://api.telegram.org/bot<TOKEN>/setWebhook?url=<URL_WORKER>&secret_token=<WEBHOOK_SECRET>
```

ตัวอย่างที่กรอกครบแล้ว:

```
https://api.telegram.org/bot8445798616:AAFfkV.../setWebhook?url=https://rain-bot.supramitj.workers.dev&secret_token=bpk-rain-2569-xyz
```

**ถ้าสำเร็จจะขึ้น:**

```json
{"ok":true,"result":true,"description":"Webhook was set"}
```

---

## ขั้นที่ 6 — ทดสอบ

1. **ปิด `rain_bot_interactive.py` บนคอมก่อน** (กด Ctrl+C ในหน้าต่าง cmd)
2. เปิด Telegram พิมพ์หาบอท: `ตอนนี้`
3. ควรได้คำตอบภายใน 1-3 วินาที

### ✅ เสร็จแล้ว

ตอนนี้บอทตอบได้ตลอด 24 ชม. แม้ปิดคอม ปิดเน็ตบ้าน หรือไปต่างจังหวัด

---

## แก้ปัญหา

| อาการ | สาเหตุ | แก้ |
|---|---|---|
| พิมพ์แล้วเงียบ | webhook ยังไม่ได้ตั้ง | เช็คด้วย `https://api.telegram.org/bot<TOKEN>/getWebhookInfo` ดูว่า `url` ตรงไหม |
| ตอบบ้างไม่ตอบบ้าง | สคริปต์บนคอมยังรันอยู่ | ปิด `rain_bot_interactive.py` |
| `getWebhookInfo` มี `last_error_message` | Worker มีบั๊กหรือค่าลับผิด | ดู Log ในหน้า Worker → **Logs** → **Begin log stream** |
| ตอบว่า `❌ เกิดข้อผิดพลาด` | Open-Meteo ล่มชั่วคราว | รอสักครู่แล้วลองใหม่ |
| เปิด URL Worker ในเบราว์เซอร์แล้วขึ้น error | โค้ดวางไม่ครบ | วางใหม่ทั้งไฟล์ แล้ว Deploy |
| อยากกลับไปใช้แบบรันบนคอม | — | เปิด `https://api.telegram.org/bot<TOKEN>/deleteWebhook` แล้วรันสคริปต์บนคอมได้ตามเดิม |

## แก้ไขทีหลัง

**เปลี่ยนพิกัดไซต์งาน** — Settings → Variables → แก้ `WX_LAT` / `WX_LON` / `WX_PLACE` → Deploy

**เพิ่มคำสั่งใหม่** — Edit code → เพิ่มฟังก์ชันและเพิ่มบรรทัดใน `ROUTES` → Deploy
บอกผมได้ถ้าอยากได้คำสั่งอะไรเพิ่ม

**ดูว่ามีคนใช้เท่าไร** — หน้า Worker จะมีกราฟจำนวนคำขอให้ดู

## ค่าใช้จ่าย

โควตาฟรีของ Cloudflare Workers: **100,000 คำขอ/วัน · CPU 10 มิลลิวินาที/คำขอ**

การใช้จริงของคุณ: พิมพ์ถามวันละ 20-50 ครั้ง = **0.05% ของโควตา**

ไม่มีทางเกิน และ Cloudflare ไม่คิดเงินอัตโนมัติ ถ้าเกินโควตาจะหยุดทำงานเฉย ๆ ไม่เรียกเก็บเงิน
