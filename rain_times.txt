#  กรอก 2 แบบ บรรทัดละ 1 รายการ:
#
#    2026-08-04 14:20 15:10     = วันนั้นฝนตกช่วง 14:20 ถึง 15:10
#    2026-08-05 -               = วันนั้นเฝ้าดูแล้ว ไม่มีฝนเลยทั้งวัน
#
#  วันไหนฝนตกหลายรอบ ก็เขียนหลายบรรทัดของวันเดียวกันได้

#    2026-08-06 16:00 17:30
#
#  ⚠️ สำคัญ: "วันที่ไม่ได้เขียนไว้ในไฟล์นี้เลย" จะถูกข้ามทั้งวัน
#     ไม่ได้ถูกนับว่าไม่มีฝน — จงใจทำแบบนี้ เพราะถ้านับวันที่ลืมจด
#     ว่าเป็นวันไม่มีฝน สถิติจะเพี้ยนโดยที่เราไม่รู้ตัว
#     วันไหนไม่มีฝนจริง ๆ ต้องเขียนบรรทัด "-" ให้ด้วย
